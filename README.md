# TO DO Web Application

A web-based **TO DO application** built with **Bootstrap**, designed to help users organize and manage their events and tasks.

## Features

* Add events with detailed information
* Edit and delete existing events
* Calendar view
* Search for events
* Share events with other users
* View events shared by other users

## How to Run

To check how the project works, you will need a development environment that supports programming in C#.

1. Download the repository to your device.
2. Open the project in a development environment that supports C# programming.
3. Start debugging.
